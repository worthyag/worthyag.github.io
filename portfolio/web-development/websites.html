Global Flavour

Global Flavour is the first website that I built using webpack. I also utilised HTML, CSS/SCSS, and JavaScript. Global Flavour has a modern web design, and its look emulates that of a restaurant's menu. The site could be improved by reducing the image file sizes for faster loading, or perhaps used CDNs to optimise the images. I also used SASS for the styling of this website to make use of mixins and to speed up the development process. Overall it is a cute website developed as a way for me to practice using webpack.
