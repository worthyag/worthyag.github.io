OtoDecks DJ App

OtoDecks DJ App is an application built using C++ and the JUCE library. The aim was to develop a DJ application with custom deck control and music library. I accomplished the following:

  • Developed OtoDecks DJ App using C++ and the JUCE library, creating a sophisticated DJ application with custom deck control and music library features.
  • Engineered an intuitive user interface allowing seamless loading of audio files, simultaneous playback of two tracks, and dynamic mixing through volume and speed adjustments, enhancing the DJing experience.
  • Implemented a custom deck control component to provide users with precise playback control, leveraging advanced object-oriented programming principles such as polymorphism and inheritance to ensure robust functionality and extensibility.
  • Designed and integrated a comprehensive music library component, enabling users to effortlessly manage their music collection within the application, streamlining access to their favourite tracks for seamless mixing.
  • Leveraged a range of technologies including C++, JUCE library, and object-oriented programming concepts such as classes, pointers, abstraction, interfaces, and encapsulation to create a robust and versatile DJ application.
