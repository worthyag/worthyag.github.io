Plan2Eat Meal App

Plan2Eat is a web application built using JavaScript, EJS, NodeJS, and MySQL. I worked on the Plan2Eat app with three other individuals for a university project, where a group member and I took charge of the programming, and the other two members oversaw the reporting and testing. However, the main purpose of this university project was to display agile methodology and team working abilities- therefore we all contributed to creating an optimal team working environment and effective planning.

Our aim for the Plan2Eat app was to create an app that allowed users to record recipes, meal plan, and create grocery lists. The app was to consist of 3 main pages- Recipes, Planner, and Grocery List to improve the efficiency of the user's meal preparation activities. The report below expands on our process.

PluggedIn App

PluggedIn is a web application built using JavaScript, EJS, NodeJS and MySQL. I worked on this for a university project. The aims of the project were as follows:

  • Create a home page that links to other pages.
  • Create an add device pages that allows users to add a new device to the database.
  • Create a show device page that displays the already added devices and their respective data.
  • An update device page that allows users to update device settings.
  • A delete device page that allows users to remove devices from the database.

The purpose of the project was to learn the skills needed to create client-server applications and query processing. I learnt about relational database systems from a development perspective. I also learnt how to model data in a database, retrieve data, and provide access to data.
